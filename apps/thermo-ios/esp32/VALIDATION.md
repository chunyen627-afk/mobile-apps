## 可重跑的裝置驗收

從同網段電腦用 `curl http://<閘道IP>:18787/sensors`，每隔 3 秒共 20 次，不加自動重試，記錄退出碼、HTTP 狀態及 JSON。確認 time 接近現在、time − updated 合理；age 大可能是廣播遺失／停止，不能只看 HTTP 成功。

至少運行一小時後讀 `http://<閘道IP>:18787/history?id=<感測器位址>&range=day`，確認 points 非空且 `(t + utc_offset) % 1800 == 0`；序列 LIVE 的 boot 識別碼與 uptime 檢查是否重啟。滿 30 天容量與斷電復原另行驗收。日誌只存已忽略的 artifacts 目錄，公開前移除私人位址、名稱與網路設定。
