# 桌面遙控（desk-remote-ios）

用 iPhone 原生輸入操作自己 Windows 電腦上的 Claude 桌面版與 Codex 桌面版：看對話清單、打字送出、看回覆、按權限的「允許一次」／「拒絕」，並在手機核准需要管理員權限的指令（`elevate`）。

## 驗證狀態

| 項目 | 狀態 |
| --- | --- |
| 設計 | [DESIGN.md](DESIGN.md) 草稿，**待使用者核准** |
| iPhone App | 尚未實作 |
| 電腦端小幫手 | 尚未實作（可行性已在本機以探針腳本實測，探針不進倉庫） |
| 模擬器測試、實機 | 尚未進行 |

之後會成為[工具箱](https://github.com/chunyen627-afk/mobile-apps/tree/claude/toolbox-ios/apps/toolbox-ios)的第三個分頁。
