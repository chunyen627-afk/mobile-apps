# Watch7 橋接（手錶專用 App）

讓 Samsung Galaxy Watch7（Wear OS）直接接收 iPhone 的通知、來電提醒與媒體控制。這是裝在手錶上的 App，不是手機 App，所以放在 `watch/` 分類，不在 `apps/`。

## 預計做什麼

第一版只有手錶端 App，iPhone 上不需要安裝任何東西：

- iPhone 的通知顯示在手錶（含 LINE 等 App 的文字通知），清除同步
- 來電提醒，可接聽或拒接
- 控制 iPhone 正在播放的音樂
- 顯示 iPhone 電量與連線狀態

用的是 Apple 公開給藍牙配件的通知服務（ANCS）與媒體服務（AMS）。

## 已知限制

- 不能在手錶上回覆訊息。
- 手錶首次設定仍需要一支 Android 11 以上的手機，設定完成後才能安裝這個 App。
- 沒有「iPhone 導航、手錶同步顯示轉彎」；手錶上的 Google 地圖要靠手錶自己的網路。
- 連線偶爾需要手動重連；耗電尚未量測。
- One UI 9 Watch（Wear OS 7）尚未有人測過，開發期間建議先不要更新手錶。

## 建置與安裝（規劃）

- Kotlin，Wear OS，目標 API 36。在 Windows 上以 JDK 21 與 Android SDK 建置。
- 以無線 ADB 安裝到手錶，不經商店。
- 安裝後要把 App 從手錶的「休眠中的應用程式」清單移除，並在 iPhone 的藍牙設定開啟「分享系統通知」。
